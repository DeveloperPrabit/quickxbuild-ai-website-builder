# Next.js SEO storefront (optional)

Opt-in catalog for generated shops. Admin, auth, and checkout stay on Vite + Hono (`:5174` / `:8787`).

```bash
cd apps/next-shadcn-template
bun install
bun dev
```

Set `APP_API_URL=http://127.0.0.1:8787` and `LOCAL_NEXT_PREVIEW_URL=http://localhost:3005` to have QuickXBuild start this stack beside Vite.
